# SLH_HAWK Parent — تحديث المصدر 1.0.5

هذا التحديث مخصص للمشروع الحالي، ويحافظ على اسم قاعدة البيانات المحلية `slh_hawk_parent_v101.db` حتى لا يبدأ التطبيق بقاعدة بيانات جديدة عند التحديث.

## التحسينات
- اختيار الابن من قائمة منسدلة عند إضافة أو تعديل مباراة أو حصة تدريبية.
- اختيار تواريخ الميلاد والمباريات والحصص وفترات الانتماء من التقويم.
- اختيار صورة ملف الابن من معرض الهاتف وحفظ نسخة داخل مجلد التطبيق.
- اختيار شعار الجمعية/النادي من معرض الهاتف وحفظه داخل مجلد التطبيق.
- معالجة ملاحظات التحليل المتعلقة ببنية if والمتغير غير المستعمل واستعمال BuildContext بعد الانتظار.
- تحديث رقم الإصدار إلى 1.0.5.

## طريقة التحديث عبر GitHub وCodemagic
1. احتفظ بنسخة احتياطية من مستودع GitHub الحالي.
2. ارفع محتويات هذا الأرشيف إلى جذر المستودع مع استبدال الملفات التي تحمل الأسماء نفسها.
3. تأكد أن `codemagic.yaml` في جذر المستودع.
4. شغّل Workflow الخاص بـ Android.
5. لا تحذف التطبيق القديم من الهاتف قبل التأكد من نجاح تثبيت التحديث وظهور البيانات السابقة.

## ملاحظة مهمة
هذا أرشيف مصدر Flutter وليس ملف APK. يجب أن ينجح `flutter analyze` والاختبارات والبناء في Codemagic قبل اعتماد APK. لم يتم تنفيذ Flutter SDK في بيئة إعداد هذا الأرشيف، لذلك لا يُدّعى أن APK قد اختُبر هنا.
